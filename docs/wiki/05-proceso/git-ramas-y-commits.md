# Ramas y commits

Parte de `main` actualizado y trabaja en una rama propia. Para trabajo vinculado al backlog usa `<tipo>/HU-###-<descripción>`. Usa mensajes breves con el formato `<tipo>(<área>): <acción> [HU-###]` cuando corresponda. Acuerda con el responsable antes de intervenir en su rama.

La integración a `main` sigue la [política de pull requests](../../../CONTRIBUTING.md#pull-requests-y-releases).
