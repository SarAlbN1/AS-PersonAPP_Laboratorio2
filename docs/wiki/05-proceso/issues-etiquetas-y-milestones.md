# Issues, etiquetas y milestones

El [backlog único](../06-backlog/README.md) define las historias, sus dependencias, prioridades, milestones M1–M3 y épicas. Para cada issue publicada, conservar el ID HU, asignar el milestone y la épica indicados y registrar a la persona responsable. La épica de modernización queda diferida.

Las etiquetas describen el tipo o área de trabajo. Los estados del tablero, si el equipo decide usarlo, se actualizan con evidencia. [Configuración de GitHub Projects](../06-backlog/configuracion-github-projects.md).
